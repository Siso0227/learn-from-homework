# 私人课程配置示例（虚构）

放在私人课程目录使用，路径相对于该目录。下列均为演示信息。

- 课程：示例课程
- 辅导语言：中文（虚构用户选择）
- 作答语言：英文（虚构用户选择，须符合课程要求）
- 材料：`lectures/`；题目：`assignments/practice.pdf`
- 评分/资源限制：从本次作业说明读取，未确认部分标待核实
- 截止：由用户或当前作业确认，含日期、时间、时区
- 节奏：边辅导边做；切换由用户选择
- 学习基础：用户自述与实际诊断分别记录

## 偏好与来源（仅经同意持久保存）

- 教学偏好：先举短例子再解释公式（用户明确；可跨课程复用）
- 作业表达：英文短句，沿用课件术语（本课程；用户明确）
- 暂定观察：长段解释可能不易吸收（待核对，不视为固定类型）
- 外部来源授权：本次尚未授权；缺资料先询问
- 记录维护：用户可查看、修改、删除；不保存无关个人资料

## 续接记录（按需）

记录完成方式、辅导/作答语言、已处理题号、答案验证情况、理解证据、未解问题与下一步。不要将“已看过解答”记为“可独立解题”。暂停或阶段结束时按需更新，不每轮重复；仅经同意持久保存。
